# YaoYoroZu — 顔加工MVP

カメラ映像をリアルタイムで「可愛く＋少し違う顔」に変換するプロトタイプ。
WebRTC通話に乗せる前の**心臓部（映像加工）**を、ブラウザだけで確認するためのもの。

## できること
- カメラ映像に対してリアルタイムで：
  - **美肌**（肌の平滑化）
  - **明るさ・血色**
  - **目を大きく**
  - **輪郭スリム**
- プリセット：`ナチュラル` / `可愛い` / `別人寄り`
- 「加工前と比較」ボタン（長押し中は素の映像）
- 加工済み映像は `canvas.captureStream()` で取得可能 → 次フェーズでWebRTCに接続

## 仕組み
1. `getUserMedia` でカメラ取得
2. **MediaPipe FaceLandmarker** で顔の478点を検出（虹彩含む）
3. 目の中心・輪郭・顔オーバルを算出し **WebGL2 シェーダ** でワープ＋美肌
4. 出力canvasを表示（＝通話相手に届く映像の素）

## 動かし方
ブラウザのカメラは `https` か `localhost` でのみ動きます。ローカルサーバで開いてください。

```bash
cd web
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く → 「カメラ開始」
```

初回はMediaPipeのモデル（CDN）を読み込むため数秒かかります。

## 注意
- `別人寄り` プリセットは輪郭・目元を強く変えるため、値を上げすぎると映像が崩れます。方向性確認は `ナチュラル〜可愛い` 推奨。
- リアルタイムの「別人級の顔差し替え」はこの構成の範囲外（遅延・破綻が大きい）。まずはフィルタ美顔＋軽い変形で。
